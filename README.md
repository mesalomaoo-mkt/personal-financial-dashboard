# 💰 Power BI Personal Financial Dashboard
 
## Overview
 
This Power BI dashboard was developed to monitor personal financial performance, providing insights into income, expenses, savings, and spending behavior over time.
 
## Business Objectives
 
- Track income and expenses
- Monitor financial health
- Analyze spending categories
- Compare revenue and expenses over time
- Support better financial decision-making
 
## Tools Used
 
- Power BI
- Power Query
- DAX
- Excel
 
## Key KPIs
 
- Total Revenue
- Total Expenses
- Savings Amount
- Savings Rate
- Revenue by Category
- Expenses by Category
 
## Dashboard Features
 
- Dynamic year filter
- Revenue analysis by category
- Expense analysis by category
- Monthly revenue vs. expense comparison
- Annual revenue and expense trends
- Financial performance monitoring
 
## Key Insights
 
- Salary represents the primary source of income.
- Housing is the largest expense category.
- Revenue remained higher than expenses throughout the analyzed period.
- October and December showed the highest revenue values.
